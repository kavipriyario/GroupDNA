# GroupDNA

### WhatsApp Chat Analyzer

GroupDNA is a Python-based project that analyzes WhatsApp group chat data and discovers interesting messaging and activity patterns among group members.

---

## About

This project analyzes an exported WhatsApp group chat and converts raw chat messages into useful insights.

The analysis focuses on understanding:

- Group activity
- Individual member activity
- Most active days
- Most active hours
- Messaging patterns

---

## Dataset

The project uses the `hostel_bois.txt` WhatsApp chat dataset.

- Participants: 6
- Duration: 60 days
- Format: WhatsApp exported chat text file

---

## Features

- Chat parsing
- Group overview
- Messages per person
- Busiest day
- Busiest hour
- Member activity analysis
- Basic chat statistics
